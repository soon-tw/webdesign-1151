先學會打開終端機

課程進度：準備工具本頁概念：終端機

安裝與建專案都靠指令，先知道指令打在哪裡。

  • macOS：Spotlight 搜尋「終端機」。

Terminal先檢查
node -v
npm -v
ng version
說明結果怎麼看
// 顯示版本號：已經安裝
// command not found：還沒安裝
這頁記住：指令打在終端機；先用 -v 檢查有沒有裝。

課程進度：準備工具本頁概念：Node.js

到官網下載 LTS 版，像一般軟體一樣安裝。

確認 Node 與 npm

課程進度：準備工具本頁概念：node -v／npm -v

兩個指令都有版本號，才算安裝成功。

  • node -v：Node.js 的版本，要 v20.19 以上。
  • npm -v：npm 的版本，例如 10.x。
  • 看到 command not found：重開終端機再試。
  • 還是找不到：回上一頁重新安裝。
Terminal輸入指令
node -v
npm -v
說明範例輸出
// v22.12.0（只要 20.19 以上即可）
// 10.9.0
這頁記住：node -v 與 npm -v 都要看到版本號。

npm 是什麼

課程進度：準備工具本頁概念：npm

npm 是套件管理員：幫你下載專案需要的別人寫好的程式。

  • package.json：記錄專案需要哪些套件。
  • node_modules：下載下來的套件，很大，不用改、不上傳。
  • npm install：依 package.json 把套件補齊。
  • -g：安裝到整台電腦，而不是單一專案。
Terminal常用指令
npm install
npm install -g <套件名>
npm run start
說明各自做什麼
// 補齊目前專案的套件
// 全域安裝，任何資料夾都能用
// 執行 package.json 裡的 start
這頁記住：package.json 是清單，node_modules 是下載結果。

課程進度：準備工具本頁概念：VS Code

VS Code 是本週寫程式的地方。

擴充套件：怎麼安裝

課程進度：準備工具本頁概念：Extensions

只裝幾個有用的，跟著清單一個一個裝。

  • 左側積木圖示（Ctrl + Shift + X），搜尋名稱，按 Install。
  • 或把右側指令貼到終端機，一次裝好（需要 code 指令）。
  • 認明發行者與安裝數：Angular、Microsoft 等，安裝數上百萬。
  • 裝太多會拖慢編輯器，不要為了好看亂裝。
Terminal一次安裝四個
code --install-extension Angular.ng-template
code --install-extension esbenp.prettier-vscode
code --install-extension usernamehw.errorlens
code --install-extension yoavbls.pretty-ts-errors
說明指令格式
// code --install-extension 發行者.套件名
// 完整名單見下兩頁
這頁記住：搜尋名稱或用指令安裝；下兩頁有完整清單。

安裝 Angular CLI

課程進度：準備工具本頁概念：Angular CLI

用 npm 把 ng 指令裝到整台電腦。

建立專案：ng new

課程進度：建立專案本頁概念：ng new

一行指令，建出完整的 Angular 專案。

  • 先 cd 到你要放專案的資料夾，例如桌面。
  • 專案名稱用小寫英文與連字號。
  • 若還有提問：需要路由選 Yes，AI 工具選 None，其餘按 Enter。
  • 過程會自動 npm install，約 1–3 分鐘。
Terminal建立專案
cd Desktop
ng new midnight-menu --style=css --ssr=false --zoneless --skip-tests
說明旗標意思
// --style=css：用純 CSS
// --ssr=false：不做伺服器渲染
// --zoneless：與課堂範例一致
// --skip-tests：不產生測試檔
這頁記住：ng new 專案名 加四個旗標，與課堂範例一致。

啟動預覽：ng serve

課程進度：建立專案本頁概念：ng serve

開發伺服器跑起來，網頁就能在瀏覽器看到。

  • 在 VS Code 終端機（Ctrl + `）輸入 ng serve。
  • 看到 Local: http://localhost:4200/ 就用瀏覽器開它。
  • 存檔後瀏覽器會自動更新，終端機要一直開著。
  • 停止預覽：Ctrl + C。
Terminal啟動預覽
ng serve
說明重點
// 紅字是錯誤，先看終端機
// 埠號被占用：ng serve --port 4300
這頁記住：ng serve 要一直開著；存檔就會自動更新。

用 CLI 產生元件

課程進度：手把手新增檔案本頁概念：ng generate component

CLI 也能一次建好元件的檔案，與手動建立擇一使用。

  • ng generate component 可縮寫成 ng g c。
  • 預設會建 pages/home/ 資料夾，內含 .ts、.html、.css。
  • 加 --flat 就不建子資料夾。
  • 類別名稱是 Home；課堂範例用 HomePage，建完需自行改名。
Terminal產生元件
ng generate component pages/home
ng g c pages/home --flat
說明差別
// 第一行：pages/home/home.ts
// 第二行：pages/home.ts（無子資料夾）
這頁記住：CLI 建檔快，但類別名稱要自己對齊範例。

卡關：指令與權限

課程進度：卡關與驗收本頁概念：常見錯誤（一）

指令跑不出來，先對照這四種情況。

  • ng 找不到：關掉終端機重開，再 ng version。
  • Windows 出現 ng.ps1 無法載入：用右側指令放寬執行原則。
  • macOS／Linux 出現 EACCES：不要用 sudo，請老師協助。
  • Node 版本太舊：回 nodejs.org 重新安裝 LTS。
PowerShell只在 Windows 執行
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
說明注意
// 詢問時輸入 Y 確認
// 只影響目前使用者
這頁記住：先重開終端機；權限問題再用右側指令。
