期末重點：資料要記得住

03 / 04　期末報告本頁主題：資料保存

評分最重的一項：資料要能記錄、能查詢。

  • 新增或修改的資料，重新整理後還在。
  • 已存的資料查得到：搜尋、篩選或排序都可以。
  • 只有寫死在程式裡的假資料，這一項拿不到分。
  • 報告用畫面截圖（或現場 Demo）呈現：新增 → 重新整理 → 查詢。
圖解 C｜報告裡怎麼證明「資料記得住」
這頁記住：新增 → 重新整理 → 查得到，三步都要成立。

1/7 期末報告怎麼進行

03 / 04　期末報告本頁主題：報告流程

報告一定要有作品畫面；現場 Demo 選做，有 Demo 分數會比較高。

  • 先用一句話說：這個作品替誰解決什麼麻煩。
  • 用畫面截圖介紹系統流程，一步一步走過主要功能。
  • 照期中計畫的驗收句，逐條附上對應畫面。
  • 資料保存要有畫面：新增 → 重新整理 → 查詢。
  • 最後說明：和期中計畫相比，改了什麼、為什麼。

驗收句範例

當我刊登一本書，我應該在清單裡看到它。

當我重新整理頁面，剛才那本書應該還在。

當我搜尋「微積分」，我應該只看到書名含「微積分」的書。

當查不到資料，我應該看到「沒有符合的書」而不是壞掉。

這頁記住：報告一定要有畫面；現場 Demo 選做，有 Demo 分數較高。

04 / 04　接下來的課程本頁主題：逐週升級

每週課堂範例都是選做；建議把當週學到的直接加進自己的作品。

  • 12/3 上線：作品有自己的公開網址。

  • 12/17 SEO：讓搜尋引擎與 AI 看得懂你的網站。
  • 12/24 表單與資料保存：期末最重要的一週。
  • 12/31 延伸應用：選做 3D 或 PWA。

每週上完課，問自己一句

「今天學的，能不能加到我的作品裡？」

能，就當週加進去；到了 12/31，作品自然就完成大半。

卡住了，下一週上課直接問。
