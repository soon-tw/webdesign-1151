ix

CSS 是什麼：把外觀從結構分離

  • HTML 回答「這是什麼」
  • CSS 回答「它長什麼樣子」
  • 同一份 HTML，換一份 CSS 就換一個樣子
一條規則的長相

x

四種選取器與它們的權重

寫法說明權重
h1標籤選取器，全站同種標籤0001
.cardclass 選取器，可重複套用0010
#topid 選取器，全頁唯一0100
style="…"行內樣式，最優先但難維護1000
!important加在宣告後面，蓋掉上面全部例外
寫法是 color: red !important;——它不是第五種選取器，而是寫在「值」後面的例外，會蓋掉整份權重。 好用，但會讓後面的維護變難，能不用就不用。

xi

權重：同一個元素，誰說話比較大聲

  • 多條規則命中同一個元素時，權重高的贏
  • 權重相同時，後寫的贏
  • 愈「精確」的選取器，權重愈高
  • 行內樣式最強，但能不用就不用

多重 class：先定義基礎，再局部覆蓋

  • 一個元素可以同時掛多個 class
  • 第一個 class 定義基礎外觀
  • 第二個 class 只負責覆蓋差異
同一顆按鈕，兩種顏色

xiii

「我明明寫了」的四種原因

  • 沒對到：class 拼錯或漏了「.」
  • 被蓋掉：行內、id 權重更高
  • 順序輸了：同權重，你寫在前面
  • 語法壞了：漏分號，整段失效
這四種症狀，用開發人員工具一秒就能看出來——下一頁教怎麼看。

Part 3｜顯示模式 display

xxv

display 決定元素怎麼活下去

  • block：各佔一整行
  • inline：並排，但上下距無效
  • inline-block：並排又可調寬高
  • none：完全不佔空間

xxvi

block：一個佔一行

  • 預設佔滿整個寬度
  • 前後都會強制換行
  • 常見：<h1>、<p>、<div>
三個 div 會各自佔滿一行

xxvii

inline：寬度由內容決定

  • 寬度隨內容而定，不換行
  • 上下的 margin 與 padding 無效
  • 常見：<a>、<span>、<b>
三個 span 會並排在同一行

xxviii

inline-block：兩者的優點都拿

  • 行內排列（不換行）＋ 區塊操縱（可調寬高）
  • 參考教材稱它「最具戰略價值」的模式
  • 把垂直清單變成水平導覽列的關鍵

xxix

display: none：徹底不存在

  • display: none：不渲染也不佔位
  • visibility: hidden：佔位但看不見
  • opacity: 0：佔位且可以做動畫
  • 除錯也很好用：先關掉一半看問題在哪
想做「淡出」動畫請用 opacity 或 visibility，不是 display——display 沒有中間狀態。

互動式網頁設計Part 4

Part 4｜定位 position

xxxiii

四種定位模式

  • static：照文件流排
  • relative：相對自己的原位
  • absolute：相對定位父層
  • fixed：相對瀏覽器視窗
互動式網頁設計勤益科大進修部

Part 4｜定位 position

xxxiv

relative：相對自己的原位移動

  • 相對於自己的原位偏移
  • 移動後，原本的空間仍保留
  • 不會把其他元素擠走
往上 8px、往右 12px
.card { position: relative; top: -8px; left: 12px; }
互動式網頁設計勤益科大進修部

Part 4｜定位 position

xxxv

absolute：父層一定要設 relative

  • 相對最近的一個非 static 父層定位
  • 父層沒設 relative，它會一路往上找
  • 最慘的結果：定位到整個網頁的邊界
父層建立定位基準
.card { position: relative; } .tag { position: absolute; top: 12px; right: 12px; }

Part 4｜定位 position

xxxvi

fixed：釘在視窗上，捲動也不跑

  • 相對於瀏覽器視窗固定
  • 捲動時釘在原地不動
  • 常見用途：置頂導覽列、蓋版廣告
把導覽列釘在最上面

Part 5｜字體排版美學

xl

font-family：字型的候選清單

  • 中文環境最安全的預設是微軟正黑體
  • 寫法是「候選清單」，用逗號分隔
  • 前面找不到，就往後退一個
一路退到 sans-serif 為止
body { font-family: "Microsoft JhengHei", "PingFang TC", sans-serif; }
互動式網頁設計勤益科大進修部

Part 5｜字體排版美學

xli

使用電腦沒有的字型

  • 使用者的電腦不一定裝了你寫的字型
  • 最簡單：用 Google Fonts 的 webfont
  • 要離線：用 @font-face 自備字型檔
  • 熱門免費中文字型：Noto Sans TC、Noto Serif TC、LXGW WenKai TC
三個步驟就能換字型
  1. 到 fonts.google.com 挑一個字型
  2. 把它給的 <link> 貼進 <head>
  3. 在 CSS 寫 font-family 指定它
中文字型檔很大（一套 5 到 15 MB），挑 1–2 個字重就好。真的要離線，得把字型子集化——只留用得到的字； 這份簡報就是這樣做的，所以斷網也正常顯示。

  • 全站建議只用 2 到 3 個主要顏色

  • 中文筆畫密，行高比英文更需要放寬

今日回顧：五個技術點，一條線

  • 選取器：先找得到元素，權重才決定誰贏
  • 盒模型：padding 撐自己，margin 推別人
  • display：block 換行、inline 不換行、inline-block 兩者兼具
  • position：absolute 記得「父層要 relative」
  • 排版：字型、字級、字距、行高，決定專業感
