常用 Class

間距 · Flex · Grid · 文字 · 顏色

互動式網頁設計Part 2

Part 2｜常用 Class

xxi

間距：p 與 m，共用一套數字

  • p-* 內距（padding）、m-* 外距（margin）
  • 數字是4 的倍數：p-1=4px、p-4=16px、p-8=32px
  • 可指邊：px-4 左右、py-2 上下
置中卡片：margin auto ＋ 內距
<div class="mx-auto p-8"> ← mx-auto 水平置中 </div> <div class="mt-6 mb-4"> ← 上 6、下 4 的間距 </div>
互動式網頁設計勤益科大進修部

Part 2｜常用 Class

xxii

Flex：最常用的一行

  • flex → 開啟 Flex 排版
  • items-center → 垂直置中
  • justify-between → 一左一右
  • gap-4 → 子項之間的間距
導覽列：logo 靠左、連結靠右
<nav class="flex items-center justify-between gap-8"> <a>LUMEN</a> <div class="flex gap-6"> <a>功能</a> <a>價格</a> </div> </nav>
互動式網頁設計勤益科大進修部

Part 2｜常用 Class

xxiii

Grid：要「多欄等寬」就用它

  • grid → 開啟 Grid
  • grid-cols-3 → 三欄
  • gap-6 → 欄與欄的間距
  • 跟 Flex 的分工：Flex 排「一列」、Grid 排「格線」
三張卡片，一格一格
<div class="grid grid-cols-3 gap-6"> <div>卡 1</div> <div>卡 2</div> <div>卡 3</div> </div>

xxiv

尺寸：寬高，和自訂數字

  • w-* 寬、h-* 高
  • size-14 寬高一起給（v4 新寫法）
  • 括號寫死：w-[180px]
  • w-1/2 一半、h-screen 滿畫面
常用尺寸寫法
<div class="w-full h-40"> ← 滿寬、高 160px <div class="w-1/2 size-14"> ← 一半寬、正方形 <div class="w-[180px]"> ← 括號裡可以塞任何值 </div>

點到 鍵盤或輸入框被選取

文字：字級、字重、顏色

  • text-* 字級／font-* 字重

顏色：一套色票＋ 60-30-10

  • bg-* 背景、text-* 字色
  • 60-30-10：60% 主色、30% 副色、10% 點綴

xxix

Mobile-first：先寫手機

  • 先寫最小螢幕（base），再往上「加」
  • 不是先寫桌面再縮到手機——方向反了會很累
  • 手機是最少的版面，往上只加欄數、加寬度
同一頁，兩個方向差很多

前綴：在 class 前面加斷點

同一個 class，加前綴就「只在那個螢幕以上生效」
